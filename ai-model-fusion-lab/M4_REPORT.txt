4. PHASE A — TOPOLOGY CIRCUITS + CAUSAL BATTERIES
------------------------------------------------------------------------------
  Pipeline per model: collect activations (task n=48, general n=48) ->
  dependency graph (causal edge = pooled activation change when node
  zeroed; structural edges from residual stream) -> motifs (chain, fan-in,
  fan-out, hub, bottleneck by min-cut, diamond, community, bridge,
  redundant paths, routing contrast, repeated transformation) -> candidate
  circuits -> causal battery:
    detection   : circuit ablation effect vs 12 random same-size member
                  sets (paired null); gate p <= 0.25 (K=12 resolution 1/13)
    correlation : mean task-selectivity of members (graph profiles)
    ablation    : MC accuracy drop on calibration split, floor = max(5, 2*std)
    restoration : patch member tensors back -> must recover; mediation
                  identity enforced (full_restore == clean, exactly)
    amplification: scale members x1.5/x2.0 (positive intervention)
  and a minimal-unit search: greedy backward elimination on the
  calibration split to retain >= 80% of circuit effect (never held-out);
  the found unit is then VERIFIED ONCE on held-out data.

  4.1 A-math (2 layers) — 9 circuits. All causal potency is real
  (effects 18-33 pts) but capability-specificity is NEGATIVE for every
  circuit (best -12.5): ablating 'math' circuits damages code/reasoning
  more than math. Verdict: capability-GENERAL infrastructure. Two
  circuits reach L5 (convergence-01/02: full ladder detection->
  correlation->ablation->restoration->amplification). Minimal units:

12. FAILURES, DEAD ENDS AND FIXES (preserved per standing rule)
------------------------------------------------------------------------------
   * graph_analysis._set_mask parsed 'mlp0' with a 4-char prefix (works
     only for 'attnN') -> ValueError. Fixed with regex in _set_mask and in
     the runner's member-key parser and _members_from_keys. Regression-
     tested (58/58 unit tests pass).
   * Graph path enumeration used causal edges only -> bottleneck None.
     Fixed to traverse causal + structural edges; bottleneck = attn0.
   * circuit batteries initially lacked the task-correlation rung ->
     everything stuck at L0. Fixed: member selectivity feeds the ladder.
   * Random-null K=6 could not resolve p<0.2; raised to K=12, gate <=0.25
     (resolution 1/13). Coarse by design; stated wherever used.
   * calibration.residual_gate saved slices keyed by tensor NAME only ->
     multi-member circuits collided (module + its heads share o.W):
     broadcast (16,64)->(64,64) crash. Fixed: per-tensor dedupe keeping
     the largest slice. This bug was invisible in all M3 single-component
     runs -- multi-member circuits exposed it.
   * Random/capacity control arms initially reused the ORIGINAL members'
     payload keys for RANDOM sites -> StopIteration (empty message).
     Fixed: _random_payload_at() draws random tensors at each random
     member's OWN sites (exact parameter match).
   * Reproduction criterion originally required beats_capacity -> an
     exactly-reproduced PARTIAL was mislabeled NOT REPRODUCED. Fixed as
     described in Section 9 (the final report says REPRODUCED-PARTIAL).
   * quick-mode deep lineage (40 epochs) is weaker than the canonical
     150-epoch pair; canonical numbers above are from the full run only.
   * Known cosmetic: registry save/load emits ResourceWarnings (unclosed
     file handles); no data impact.
